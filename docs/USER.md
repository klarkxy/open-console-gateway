# User Guide

This checkout delivers the OCG3 backend and headless CLI. Begin with the
[CLI guide](user/cli.md): it covers building and starting the host, authentication,
accounts, routing, Keys, billing, applications, transfer, and inference. It also
lists the HTTP operations and the offline schemas for their request bodies.

The React console and desktop interface are a later phase. Desktop screenshots
and installer instructions in older chapters describe published releases.

- [CLI](user/cli.md) — Start with an empty directory and send the first request.
- [Protocol conversion](user/protocol-conversion.md) — Supported inference formats and limits.
- [Providers](user/providers.md) — Provider and Plan capabilities.
- [Data security](user/data-security.md) — Credential handling and local storage.
- [Upgrade and backup](user/upgrade-backup.md) — Transfer and whole-directory recovery.
- [Maintainer guide](MAINTAINER.md) — Source builds, runtime contracts, and checks.
