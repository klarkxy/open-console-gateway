# User guide

Use the [CLI guide](user/cli.md) to build, configure, and operate this checkout. It describes the existing host and HTTP operations, not completed CPA migration.

The new version adopts a [CPA foundation](architecture.md) with a complete CLI and a planned [native GPUI/Ely GUI](architecture.md#9-native-desktop-gui) for Windows, Linux, and macOS. The GUI is not available in this checkout yet. [Migration boundaries](maintainer/cpa-migration.md) distinguish current operation from the target.

- [CLI](user/cli.md) — Empty directory to inference and ongoing management.
- [Data security](user/data-security.md) — Existing credentials and storage.
- [Upgrade and backup](user/upgrade-backup.md) — Existing transfer and recovery.
- [Maintainer guide](MAINTAINER.md) — Builds, contracts, and migration.

Other chapters retain older implementation and published-release instructions. Dashboard/desktop steps are historical references, not OCG3 prerequisites.
