# 临时停调

在 **设置** 页的临时停调区块，匹配到上游错误后会在本地跳过某把 Key 或某个模型，再等到已经走这条路线的真实流量去重试。没有新的导航项。

选择 **全局** 或某一个连接。连接上与全局相同 id 的规则会整条替换全局规则，不按字段合并。本地禁用行会挡住继承来的全局规则。删除本地行即恢复继承。

## 内置 GOAT 额度拒绝

内置 GOAT 额度拒绝匹配器是密封的。你可以在全局或某个连接上关闭它，或恢复继承。不能改成脚本、正则或原文扫描。

已分类的 GOAT 余额不足响应，本次请求仍会按既有首次回退改试下一把合格 Key。报余额不足的那把 Key 与实际上游模型随后进入本地等待。同一把 Key 在本次请求中不会再试。

其他或未知 400（上下文过长、模型或 reasoning 校验等）仍只在本次请求内失败：本页不为它们增加首次回退。自定义规则仍可装上等待，让后续请求跳过该目标；当前这次未知 400 的失败方式与原来相同。

GOAT 错误正文仍不会创建持久化额度或重置时钟。普通 `429`、Zen Free 与 OpenRouter Free 仍走原有路径。见[路由](routing.zh-CN.md)。

## 自定义规则

每条自定义规则有一种范围：

- **仅凭证** — 等待覆盖这把 Key 上的全部模型。
- **凭证与模型** — 等待绑定这条路线实际发出的上游模型，不是客户端别名。

匹配字段均可选；一旦填写就不能为空：

- HTTP 状态码 `400`–`599`
- 精确的 `error.code`
- 精确的 `error.type`
- `error.message` 的字面量子串

已填写的字段之间是 AND，同一字段内的取值是 OR。只读取有界 JSON 错误体里这些顶层结构化字段。不遍历请求回显、choices、messages 或成功正文，也不扫描原文、不用正则、不跑脚本。只填状态码的规则可以在没有解析出错误体时命中。读正文失败不会变成合成的错误文本去匹配。

## 本地等待

活动限制显示 `waiting`、`ready` 或 `probing`：

- **waiting** — 本地退避到期前跳过该目标。
- **ready** — 本条本地规则允许对该来源重探。实际发送仍须满足其他规则、有效的 `Retry-After` 和官方限制。本地退避到期（包括默认 30 秒）并不表示请求一定会发出。
- **probing** — 该请求正在发送。

列表是按来源的本地等待，不是总体可否发送。

完整且协议有效的 JSON 或 SSE 成功，只清除本次实际持有探测租约、且未被并发更新的那条限制。其他模型上的成功不会清掉它。没有后台探测，也没有周期轮询。只有实际符合这条等待路线的流量才会再发。

**清除本地等待**只丢掉这次进程内等待。它不发请求，不改启用、鉴权、额度恢复或上游 `Retry-After`，也不表示上游健康。限制表为空同样不表示上游健康。读取该列表不会探测。

全部兼容 Key 都只因本地策略等待时，Gateway 返回 `503`。因 `429` / `Retry-After` 而全部等待的语义不变。

退避默认 30 秒与 300 秒。取值是 1 到 86400 的整数，且最大值不能小于初始值。

## 持久化与拷贝

已保存的规则在重启后仍在。进程内的 waiting / ready / probing 会丢掉；重启后下一次匹配请求可以再发。已有的官方额度恢复是另一套机制，不会由这些错误正文创建。

完整数据目录备份会保留已保存规则。可移植账号导出不携带它们，导入也不会清掉目标端无关的本地规则。删除连接时，相关规则会在同一次变更中移除或停用，不会按显示名重新绑回去。

## 上限

- 总共最多 128 条配置规则
- 任一连接最多 32 条生效的启用规则
- 每个匹配字段最多 32 个取值
- 每条匹配字符串最多 256 个 UTF-8 字节
