# 管理供应商的单个模型

在**供应商**页选择一个可配置 HTTP 供应商，包括从预设创建的 HTTP 供应商和旧版 Custom API 连接。模型工具栏提供**添加模型**，以及可搜索的模型选择器和**编辑**按钮。即使从未刷新过目录、当前目录为空，也能手动添加。原有表格继续提供单模型删除和勾选后批量删除。

## 模型字段

- **上游模型 ID**：真正发送给供应商的模型标识，必填。
- **对外模型名**：客户端在 `model` 字段中使用的可调用别名，不只是显示名称。留空时直接使用上游 ID，不自动去掉后缀。同一供应商内，忽略首尾空白和 ASCII 字母大小写后不能重名；不同别名可以指向同一个上游模型。
- **上游协议**：选择该模型允许使用的已配置上游路由。**首选协议**必须包含在这些选择中。这不是客户端入口协议的拒绝列表，网关原有的协议转换仍然有效。新增或修改协议地址应进入**编辑连接**，而不是在单模型表单中修改。
- **允许路由**：启用该模型映射。启用时至少选择一种协议；停用不会删除模型。能否实际调用仍取决于连接、Key、模型范围、授权和上游状态。

已有的逐模型上游地址覆盖会原样保留，并以只读方式显示；此时只能选择该覆盖所使用的协议。修改别名会替换原行，不额外保留旧别名。跨供应商的名称冲突仍按网关现有规则处理，歧义名称不会被任意路由。

## 保存与删除

保存通过一次带 CAS 校验的 V4 连接 PATCH 完成，保留其他模型的映射、启用状态、协议选择，以及供应商已有的地址配置。不会为 Key 新增授权、扩大模型范围、自动发现模型或发送可能付费的测试请求。模型映射变化时，仍执行后端原有的验证状态失效规则。

打开表单时会捕获配置版本。其他窗口修改配置或服务重启后，旧表单不能静默覆盖新状态。过期提示中的**重试**会重新载入最新已保存字段；重新填写修改内容后再保存，不会自动重放旧请求。

使用表格中的删除操作可移除一行，也可勾选后批量删除。原有目录删除接口允许删掉最后一个模型。删除只影响本地目录，之后手动刷新时可能再次发现相同上游 ID；HTTP 模型重新发现后默认启用。需要在刷新后保留关闭状态时，应停用该行而不是删除。

## 支持范围

此编辑器不修改内置供应商的封闭适配器，也不修改 CPA。它们原有的模型、协议开关和本地删除行为保持不变；本次未为它们增加手动模型或自定义别名。少数仍保留多个隐式协议的旧 HTTP 连接，需要先在**编辑连接**中配置明确的协议路由；单模型编辑器不会静默把这些连接压缩成单协议。
