# New API 与 Sub2API 账号

每个站点是**一个账号**，下面可以有多把 Key。**添加 Key** 只填写名称和 Key。保存时按该 Key 向站点拉取可用模型，再完成关联。New API 在已保存管理凭证后，可用**从站点导入 Key**：列出远端令牌、读取完整 Key、在本地创建 Custom Key 并关联。本地已有、已停用、或无法读取完整 Key / 模型的令牌会跳过。New API 与 Sub2API 自己会做 Chat Completions、Messages、Responses 之间的协议转换，因此 OCG 不为每把 Key 选择协议，也不打开完整的模型映射编辑页。创建成功但关联失败时，会明确显示 Key 已存在，重试只执行关联。刷新页面后，已创建的独立 Key 仍可通过关联已有 Key 继续处理。创建结果不确定时，应先核对账号列表，不直接重复创建。

**New API** 和 **Sub2API** 是平台类型，不是各自只能添加一个的供应商。每个站点或用户账号分别添加一个具名实例；多个 New API 实例、多个 Sub2API 实例可以同时存在。每个实例有独立身份、站点地址、凭证、关联 Key 和观察数据。刷新、编辑或删除一个实例不会操作同类型的其他实例。

在**账号**页点击**新增账号**，从**平台账号**分组选择 **New API** 或 **Sub2API**，再填写站点地址和名称。该站点在账号列表里显示为一张可排序卡片。拖动这张卡片决定它在全局路由中的位置；卡片内的 Key 用上移/下移决定彼此之间的失败切换顺序。对某把 Key 点**获取模型**（或**获取全部模型**），会按这把 Key 调用站点的 `GET /v1/models` 并保存它自己的列表。两把 Key 出现同一对外名称是叠加，不是冲突：带鉴权的 `GET /v1/models` 只列出一次，请求按 Key 顺序失败切换。各 Key 使用自己的倍率，不会把价格平均掉。请给每把 Key 起能区分的名称（例如「Codex 稳定」和「Codex Pro」）；刷新后卡片还会显示站点分组和 Key 快照里的令牌名称。

填写站点根地址；部署在子路径时保留该路径。平台类型和地址创建后固定。你可以明确关联现有 Custom API Key，也可以在站点卡片里添加 Key；New API 在保存管理凭证后还可以从站点导入 Key。导入的 Key 秘密与手动添加的一样只存在本地，不会通过界面接口返回。手动关联不能证明远端归属或模型调用权限。关联 Key 记为对平台账号的已声明（未验证）关系。关联期间推理使用站点根地址，并把客户端的 Chat、Messages 或 Responses 原样交给上游；Gemini 客户端仍转换为 Chat Completions。

可选的用户凭证用于读取用户范围的数据。New API 分别填写个人设置里的数字用户 ID，以及「个人设置 → 安全设置 → 系统访问令牌」，不要填令牌页的推理 Key。用户 ID 会作为 `New-Api-User` 发给仍要求该请求头的站点；较新的 New API 会忽略它。Sub2API 填写登录用户的访问令牌。该凭证与推理 Key 分开保存，不通过界面接口返回，也不进入迁移包。不填写时仍可读取 Key 范围的数据。用户凭证过期不会禁用推理；清除凭证会清除依赖它的缓存观察值。

## 刷新和查看数据

数据需要手动刷新。父账号卡片在正文以 **余额** 数值显示钱包剩余，已知已用量时并列显示。每把关联 Key 行可在启用开关旁显示自己的剩余。钱包、订阅和 Key 额度属于不同范围，不能相加。

未填写可选用户凭证时，父账号钱包保持未知；请刷新各把 Key 以读取该 Key 的剩余额度。New API 的数量以站点原生 quota 点保存，并在 `GET /api/status` 返回正的 `quota_per_unit`（站点自己的点数兑美元比率）时换算为美元。没有该比率时保持 `quota` 单位。

New API 支持钱包和订阅计费、固定及自动分组、扣费偏好。Sub2API 的 billing 接口描述 Key 倍率，不是余额接口。Sub2API 当前余额来自用户资料，或来自 Key 的 `/v1/usage` 在明确提供 `balance` 字段时的观测值。模型广场的价格仅用于展示，不能证明 Key 有调用权限。明确的模型权限或通过 Key 认证的 `GET /v1/models` 决定这把 Key 可以路由的模型。刷新价格不会自动改变可路由模型。

只有模型、分组、单位和倍率均明确的固定文本 token 价格参与请求估算。自动分组、表达式、阶梯、按次或图片计费，以及无法还原的峰时规则，都不生成确定估算。价格最多有效 24 小时。已启用的峰时或分时规则仅展示、不估算。New API 匿名报价无法确定用户专属倍率，也不生成请求估算。刷新失败后，旧观察值标为过期，不用于新请求估算。

每次发往上游的请求尝试都会冻结自身的价格依据。失败切换后的 Key 使用自己的费率，后续刷新不改写历史。日志保留原币估算金额和价格来源；估算不能证明钱包实际扣款、订阅抵扣，或失败请求是否收费。

## 修改与迁移

关联 Key 的端点由父账号管理。解除关联会保留 Key、已生成的端点和模型配置。删除父账号前，需要先解除全部子 Key 的关联或删除子 Key；删除父账号不会连带删除 Key。

导出使用 V7 负载，以目的地与凭据为权威：父账号定义、关联、管理密钥和平台 extras 与推理 Key 一起只存在加密信封内。合并导入时，若包中没有 CPA 或平台 observer key，会保留目标已有 management key。导入后草稿连接在完成前不会进入路由。导入接受 V4 至 V7 负载。导入分组在获得新证据前保持未验证。同一父账号 ID 对应不同平台或站点地址时，整笔导入失败并回滚。

升级前备份完整数据目录。回滚需要恢复完整备份，不要用旧版程序打开已迁移数据库。详见[存储与迁移](../maintainer/storage-migration.zh-CN.md)。
