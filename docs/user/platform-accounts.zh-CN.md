# New API 与 Sub2API 账号

每个站点提供 **添加 Key** 和 **关联已有 Key**。添加 Key 会打开沿用站点推理地址的 Custom API 表单，路径由所选协议决定。保存先创建账号，再把这个账号关联到站点；创建成功但关联失败时，会明确显示 Key 已存在，重试只执行关联。刷新页面后，已创建的独立 Key 仍可通过关联已有 Key 继续处理。创建结果不确定时，应先核对账号列表，不直接重复创建。

**New API** 和 **Sub2API** 是平台类型，不是各自只能添加一个的供应商。每个站点或用户账号分别添加一个具名实例；多个 New API 实例、多个 Sub2API 实例可以同时存在。每个实例有独立身份、站点地址、凭证、关联 Key 和观察数据。刷新、编辑或删除一个实例不会操作同类型的其他实例。

在**账号**页点击**新增账号**，从**平台账号**分组选择 **New API** 或 **Sub2API**，再填写站点地址和名称。创建后，账号页会显示平台账号管理区域。父账号用于归组现有 Custom API Key；每个 Key 保留自己的模型映射、协议、启停、冷却状态和全局路由顺序。归组不会创建新的 Provider，也不会改变失败切换优先级。

填写站点根地址；部署在子路径时保留该路径。平台类型和地址创建后固定。你可以明确关联现有 Custom API Key，也可以先粘贴 Key 创建 Custom API 账号，再进行关联。OCG 不读取远端 Key 秘密。手动关联不能证明远端归属或模型调用权限。关联 Key 记为对平台账号的已声明（未验证）关系。

可选的普通用户凭证用于读取用户范围的数据，与推理 Key 分开保存，不通过界面接口返回，也不进入迁移包。不填写时仍可读取 Key 范围的数据。用户凭证过期不会禁用推理；清除凭证会清除依赖它的缓存观察值。

## 刷新和查看数据

数据需要手动刷新。父账号展示账号钱包和订阅；Key 展示自身限额及消耗。每项数据保留来源、单位、周期和观察时间。钱包、订阅、Key、日、周、月额度属于不同范围，不能相加；缺失字段保持未知。Sub2API Key 返回的钱包或订阅数据标明“经此 Key 观测”，手动关联不代表已经证明共享归属。

New API 支持钱包和订阅计费、固定及自动分组、扣费偏好。Sub2API 的 billing 接口描述 Key 倍率，不是余额接口。模型广场的价格仅用于展示，不能证明 Key 有调用权限。明确的模型权限或通过 Key 认证的模型发现提供候选列表，由你选择并确认导入。刷新价格不会自动改变可路由模型。

只有模型、分组、单位和倍率均明确的固定文本 token 价格参与请求估算。自动分组、表达式、阶梯、按次或图片计费，以及无法还原的峰时规则，都不生成确定估算。价格最多有效 24 小时。本版对已启用的峰时或分时规则仅展示、不估算。New API 匿名报价无法确定用户专属倍率，也不生成请求估算。刷新失败后，旧观察值标为过期，不再用于新请求估算。

每次发往上游的请求尝试都会冻结自身的价格依据。失败切换后的 Key 使用自己的费率，后续刷新不改写历史。日志保留原币估算金额和价格来源；估算不能证明钱包实际扣款、订阅抵扣，或失败请求是否收费。

## 修改与迁移

关联 Key 的端点由父账号管理。解除关联会保留 Key、已生成的端点和模型配置。删除父账号前，需要先解除全部子 Key 的关联或删除子 Key；删除父账号不会连带删除 Key。

新导出使用 V6 负载，除已有可迁移推理配置、持久化入职草稿和身份快照外，还携带父账号定义和关联关系，但不携带管理凭证、平台观察密钥或缓存观察值。导入后草稿连接在完成前不会进入路由。仍支持导入 V4 与 V5。导入分组在获得新证据前保持未验证。同一父账号 ID 对应不同平台或站点地址时，整笔导入失败并回滚。

升级前备份完整数据目录。回滚需要恢复完整备份，不要用旧版程序打开已迁移数据库。详见[存储与迁移](../maintainer/storage-migration.zh-CN.md)。
