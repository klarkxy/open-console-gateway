# 账号删除与刷新

## 删除一把本地 Key

在**账号**页打开 Key 行菜单，选择**删除账号**。普通账号，以及关联到 New API 或 Sub2API 的 Key，都提供此操作。确认后通过现有账号删除接口移除所选本地账号，不会撤销上游 Key、注销上游账号、删除同平台其他 Key，或删除供应商定义。

**取消关联**是另一种操作：保留 Key 及其已保存的推理 Endpoint，仅解除平台关联。平台账号的删除保护保持不变：先删除或取消关联其 Key，再移除父账号，不会隐式级联删除。

服务确认删除后，前端立即移除对应账号及关联。后续投影重载仅执行读取，失败会单独提示，不应因此再次提交删除。较早发起的观察结果不能把已删除行恢复到列表；后续权威账号列表可以确认导入等有意恢复的账号。

## 刷新范围

New API 或 Sub2API 平台的**刷新**更新平台观察快照；关联 Key 的刷新更新该 Key 的快照，并显示该 Key 自己的错误，不再误用父账号错误。这些刷新操作不会自动为所有关联 Key 导入模型。需要更新模型能力时，使用现有的**获取模型**或卡片级获取模型操作。

显式获取平台模型时采用增量合并，保留已有映射。部分返回或被截断的响应不会抹掉原来保存的模型。

其他账号的手动刷新保留现有伴随模型发现行为。仅支持模型发现、不提供官方额度接口的账号，也能执行模型发现，不会发送不支持的额度请求。忙碌状态覆盖额度请求和伴随任务的完整周期；额度刷新失败或被限流后，不再继续启动模型写入。自动额度刷新仍保持静默、遵守下次可刷新时间，且不执行伴随模型发现。

同一平台的相同刷新请求会复用进行中的请求；平台父账号与其子 Key 的刷新不会相互重叠。退出登录或确认删除会使在途观察失效，迟到的结果不能写入新会话，也不能解除新操作的忙碌状态。

这些修复保留 V4 API、CAS 检查和现有数据格式，不需要迁移数据，也不会修改上游账号。
