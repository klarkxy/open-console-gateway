# 旧应用功能——已退役

自 2026-09-07 起，旧 Applications 应用子系统整套退役，面板入口已经关闭。
退役范围包括旧应用教程卡片、客户端配置与模型元数据生成、Desktop 自动连接器，以及 Pi/DSH 接入模板。
这些内容不再作为受支持的贡献路径或发布验收对象。后续会另行设计新方案，本页不规定其范围或交付时间。

这份退役说明不会移除用户已经安装的客户端配置或插件。

支持填写 Base URL、Key 与模型 ID 的客户端，仍可使用普通 [Gateway 接口](gateway.zh-CN.md)、
[首个客户端教程](first-client.zh-CN.md)与[手动客户端配置](add-application.zh-CN.md)。
协议能力与限制见[协议转换](protocol-conversion.zh-CN.md)和[限制](limits.zh-CN.md)。
