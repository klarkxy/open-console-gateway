## 已确定的产品方向

- 命令为 `ocg` / `ocg.exe`，crate 为 `ocg-cli`，默认数据目录 `~/.ocg3`；保留显式 `--data-dir`、既有数据格式及 `OCG_MANAGER_ENCRYPTION_KEY`。
- `ocg3` 与 `open-console-gateway` 是同一项目的不同代际分支。
- 唯一执行基础是本地、由 OCG 管理的 CPA。OCG 负责配置、访问 Key、公开模型、Plan 证据及运行生命周期。不增加外部 CPA 产品模式、OCG 外层重试/回退，CPA 失败后也不恢复旧内核执行。
- 先完成无界面 CLI 验收，再实现 Rust/GPUI/Ely 原生 GUI。目标为 Windows/Linux/macOS，A 概览作为首页、C Plan 主从布局、B 可选紧凑模式。原生 GUI 尚未实现。

## 部分迁移和剩余工作

部分改动涉及 `cpa_test_endpoints.rs` 及其测试、`state.rs`、`usage_sync.rs`、`cpa_projection/{types,build,endpoints}.rs`。已选方案使用仅测试功能启用的实例内固定端点映射，复用现有解析器、`Arc` 和 `OnceLock`。安装必须发生在第一次渲染前；重复、过晚或竞争失败的安装拒绝；错误和缺省状态按约定封存，参与的内置端点缺失时关闭发送。不持久化测试映射元数据。

继续把同一份端点权威贯穿投影渲染、回调、实时身份、验证发送及解释，然后迁移夹具和托管验证。在网关启动前安装受控用量接口。保留分阶段 CAS 版本测量，并区分入口冲突与已发送后的过期完成。仅为禁用绑定增加明确的模型测试拒绝类型，其余基础设施失败仍返回服务错误。调用者迁移后再移除旧的全局托管目标覆盖。不能放宽重试、配额、取消、截止时间及不可重放断言。

两个精确测试仍需诊断：`failed_apply_keeps_applied_client_route_distinct_from_desired`（Excluded 与 Client 不符）和 `accepted_history_rollback_restores_the_selected_map`（原因分类不符）。第一个姿态失败已排除时钟过期解释，但实际触发的排除项仍未知。保留断言，先输出结构化非秘密事实，再决定修复。

深层隔离目录暴露了超出通常 Win32 路径上限的原子替换失败。缩短测试目录后，四种 BYOK 配置/移除全部通过；产品长路径兼容仍是独立的待处理观察。不能隐式修改全局 Windows 设置作为修复。
