# 约定

- [架构](../architecture.zh-CN.md)定义目标职责；源码与 [CLI](../user/cli.zh-CN.md)描述当前行为。目标保证不是实现证据。
- 按[迁移边界](cpa-migration.zh-CN.md)保留受支持数据、安全与兼容。CPA 是目标唯一执行/重试所有者，产品服务不成为另一个调度器。
- 配置、权威证据、执行状态和观察明确所有者与身份/版本校验。未知不能变成成功、零余额或路由禁用。
- Rust 测试放在同级 tests.rs 并检查行为；按受影响边界验证。
- 同步双语章节、链接和事实。一份主架构附迁移与证据文档。
- 根 README 是入口；能力表在 docs/user/，开发流程在 docs/maintainer/。保留的旧指南标明范围。
- 使用可移植路径和合成示例。私人账户、本机路径、个人模型/助手调度和工具不进入项目设计。
- 文档检查内容与链接；运行检查随实现变更进行。实验范围与遗漏明确记录，不是永久发布豁免。
