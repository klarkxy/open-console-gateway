# 用户指南

通过 [CLI 指南](user/cli.zh-CN.md)构建、配置和操作本分支。它描述已有宿主和 HTTP 操作，不表示 CPA 迁移已完成。

新版本采用 [CPA 底层](architecture.zh-CN.md)，提供完整 CLI，并规划面向 Windows、Linux、macOS 的[原生 GPUI/Ely GUI](architecture.zh-CN.md#9-原生桌面-gui)。本分支尚无该 GUI。[迁移边界](maintainer/cpa-migration.zh-CN.md)区分当前操作与目标。

- [CLI](user/cli.zh-CN.md) — 从空目录到推理及日常管理。
- [数据安全](user/data-security.zh-CN.md) — 当前凭据与存储。
- [升级备份](user/upgrade-backup.zh-CN.md) — 当前节点转移与恢复。
- [维护者指南](MAINTAINER.zh-CN.md) — 构建、合约与迁移。

其他章节保留旧实现与已发布版本的操作资料。Dashboard/桌面步骤是历史参考，不是 OCG3 前提。
