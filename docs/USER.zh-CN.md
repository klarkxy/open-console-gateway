# 用户指南

当前源码交付 OCG3 后端和无界面 CLI。从 [CLI 指南](user/cli.zh-CN.md)开始：
它涵盖构建与启动、认证、账户、路由、Key、计费、客户端配置、迁移和推理，
并列出 HTTP 操作及请求体对应的离线 schema。

React 控制台和桌面界面属于后续阶段。旧章节中的桌面截图和安装包说明对应已发布版本。

- [CLI](user/cli.zh-CN.md) — 从空目录启动并发送第一条请求。
- [协议转换](user/protocol-conversion.zh-CN.md) — 推理格式支持范围与限制。
- [供应商](user/providers.zh-CN.md) — Provider 与 Plan 的能力。
- [数据安全](user/data-security.zh-CN.md) — 凭据处理与本地存储。
- [升级与备份](user/upgrade-backup.zh-CN.md) — 迁移和完整目录恢复。
- [维护者指南](MAINTAINER.zh-CN.md) — 源码构建、运行约定和检查。
