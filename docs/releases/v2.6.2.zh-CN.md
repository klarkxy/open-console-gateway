# v2.6.2

[English](v2.6.2.md)

## 升级

本补丁版保留数据库 schema v63，无需数据迁移。升级前请备份数据目录。

**刷新模型目录**现在会先为旧版预设连接补齐缺少的协议路由，再刷新模型。已有地址和鉴权保持原样；新增路由不会自动获得 Key 授权，使用前请在连接编辑页复核授权。

## 变化

- 调整仪表盘布局、主题控件和键盘导航。页面导航改用 hash 路由，旧的 `?view=` 链接仍可打开。
- 账号卡片支持折叠和紧凑排序模式，可调整卡片与 Key 的顺序；折叠状态在刷新后保留。别名页展示配置中的路由顺位和平台来源。
- 减少重复页面加载、账单读取与长列表渲染。供应商品牌按已保存的预设身份显示，模型矩阵默认限制首批渲染行数。
- 修复切换 Key 或重命名平台后立即排序的版本冲突，避免拖拽破坏 Vue 行结构，并恢复远程浏览器画面缩放后的正确点击坐标。
- 发布复用同一提交已通过的 Quality 检查，桌面产物发布后自动启动容器发布。

## 验证

Windows 本地检查通过：Node.js 22 下的 820 项前端测试、96 项工具测试、Web 构建及发布预检。使用隔离虚拟数据的浏览器检查通过了 Key 脱敏与复制、切换开关后立即排序、拖拽后删除、别名页、历史导航及 390 px 布局。Gateway Lab 的 98 项场景全部通过，远程调用为 0，进程和端口清理已确认。noVNC 原生缩放通过坐标检查，未运行真实远程桌面会话。

最终 main Quality、各平台打包和容器发布分别作为发布关卡。本地未使用真实供应商请求，也未运行安装器交互及 macOS、Linux 桌面会话。

更新包使用 Tauri minisign 签名。Windows 安装器无 Authenticode 签名；macOS 应用使用 ad-hoc 签名，未公证。
