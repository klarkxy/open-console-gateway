# v2.6.3

[简体中文](v2.6.3.zh-CN.md)

## Upgrade

Database schema remains v63. Stop processes using the data directory and back up the whole directory before upgrading. Saved temporary-unavailability rules survive restart; active local waits do not. Portable account exports do not include these rules. Earlier versions do not enforce them; restore the pre-upgrade backup when rolling back.

## Changes

- Add global and per-connection temporary-unavailability rules in Settings. Match structured upstream errors, inspect local waits, and clear a wait without sending a probe. GOAT credits rejection has a built-in rule; retries use ordinary client traffic and still respect independent Retry-After limits.
- Install, replace and remove the OCG plugin through a running DSH Web or official Desktop address. Detect local profiles, use the selected Home's session context, and report applied, restart-required and unconfirmed results. DSH Editor profiles retain their separate local installation path.
- Protect rule edits and wait clearing with the revision and process identity of the displayed data. Account cooldown resets also fence delayed error responses.
- Refresh stale account usage while the Accounts view is active, hide disabled alias mappings, and simplify model selection with visible-row and all-filtered selection.
- Present successful unpriced requests as success in Logs and include them in the success filter. Keep missing prices distinct from zero cost.
- Update the mascot, desktop icons and favicon; revise paired user and maintainer guides. The Codex integration document is a proposal, not an enabled feature.

## Verification

Local Windows checks passed under Node.js 22.23.3: focused frontend tests, 88 Gateway Lab tooling tests, the web build, V4 contract check, Rust Clippy, 35 recovery tests, 48 DSH host tests and 20 policy/resource HTTP tests. The temporary-policy Lab passed all 20 scenarios with zero remote calls and verified process/port cleanup. DSH CLI 0.1.7-rc.2 passed plugin credential import and a loopback streaming call, Home discovery and Editor profile installation. Isolated DSH Web and the installed official Desktop Host passed install, replacement and removal through OCG; their original bundle lists were preserved. The Desktop runtime did not provide a version in this test report. Main Quality, native packaging and container publication remain separate gates for the exact tagged commit.

No real supplier calls, interactive installer checks or macOS/Linux desktop sessions were run for this release preparation. Updater payloads carry Tauri minisign signatures. Windows installers have no Authenticode signature; macOS apps use ad-hoc signing and are not notarized.
