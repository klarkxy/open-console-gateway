# v2.6.0

[English](https://github.com/klarkxy/open-console-gateway/blob/v2.6.0/docs/releases/v2.6.0.md)

## 升级

升级前停止使用数据目录的进程，并备份整个目录。数据库由 schema v62 迁移到 v63；旧版程序不能打开升级后的数据库，回滚需要恢复升级前备份。

安装或升级桌面应用后，首次启动会同步内置 Codex skill。原生命令行正式版在启动 `serve` 时也会同步；可通过 `ocg-manager-cli skill sync` 显式执行。Skill 安装在当前用户的 `~/.agents/skills/ocg-manager`。替换旧的 OCG 托管版本前会备份；同名非托管 skill 或已在当前内置版本上做本地修改的 skill 会保持原样。容器不会向宿主机安装 skill。

## 变化

- 保存按模型划分的协议路由和明确的端点授权。供应商目录与账号操作展示这些选择，不再依靠模型名称推断协议；Kimi 滚动模型 ID 保留原始拼写。
- 探测和路由共用已保存的 HTTP 路由；修复授权目标选择、站点子路径、额度错误分类、请求归属和过期账号刷新造成的错误状态。平台关联账号回退时，只有实际发送的端点仍属于已保存路由，才保留原币种价格归属。
- 内置协助本机下载、安装、部署、配置、升级和排障的 agent skill。已安装版本的 CLI `--help` 是命令语法和能力范围的准确信息。真实 Key 由用户在本机面板或客户端填写，agent 不应要求把 Key 发到对话中。
- 普通 CLI `status` 和 `serve` 输出隐藏 Gateway Key；只有用户在私人终端显式运行 `status --show-key` 才会显示。
- 项目许可证更新为 SATA 2.1；点赞和致谢是邀请，不再是使用条件。

## 验证

Windows 本地验证通过 768 项前端测试和 2,230 项 Rust 工作区测试（九项需主动启用的测试跳过）。发布工具测试、设计规范检查、V3/V4 契约检查、类型检查、前端构建及未签名版本预检均通过。本地 Gateway Lab 全套通过，`remoteCalls=0`，进程和端口清理已验证。

已构建未签名的 Windows 安装器和原生 CLI ZIP，两者均与 `SHA256SUMS` 匹配。从 ZIP 解压的 CLI 可以启动面板；普通 `status` 与 `serve` 输出隐藏 Gateway Key；首次启动在隔离用户目录安装内置 skill，再次同步显示已是最新。正式标签工作流将在发布前另行构建并验证 Windows、macOS、Linux 的签名更新包。

本地未进行真实供应商请求、桌面交互式安装和升级、桌面首次启动时的 skill 同步、SmartScreen、macOS/Linux 桌面操作、浏览器配置持久化及客户端 Key 剪贴板内容检查。没有把真实凭据交给 agent 工具或测试产物。

更新包使用 Tauri minisign 签名。Windows 安装器无 Authenticode 签名；macOS 应用使用 ad-hoc 签名，未公证。
