## Main-only quality repairs

The original main snapshot failed two Alias expectations, four Rust fixtures and two lint checks. This patch keeps raw Go model aliases and the explicit-protocol safety behavior: an unknown catalog ID does not imply Chat support. The tests now cover unknown Zen enable/disable/reset behavior, unknown Go Auto versus ForceOn, disabled raw alias rows, and removal of an explicitly enabled proxy route. Two lint-only changes remove an unused import and use slice membership directly.

Repairs are staged as a main-derived Git commit without creating a branch. All existing Quality jobs validate that exact commit before main can advance or version preparation can run. No failing test is skipped or removed. Workflow results, not this note, determine validation status.
