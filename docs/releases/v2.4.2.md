# v2.4.2 patch package preparation

Source: `main` at `27991937903373e24e6000e15793b5fa7047cfce`, including the 19 commits after `v2.4.1`. No unmerged feature branch is included.

The one-shot `Prepare v2.4.2 main patch packages` workflow runs the existing Quality gate before changing the version. Cargo regenerates the workspace lockfile; preparation rejects external dependency changes. Version manifests and Compose image defaults advance together. The default `pnpm run test` also includes the existing tooling regression suite.

Native candidates are built by the unchanged `release.yml` workflow for Windows x64, macOS Universal and Linux x64. Download its platform artifacts after the run succeeds. A successful preparation or dispatch alone does not mean that native builds passed.

This preparation does not publish a release, create a tag, change stable update channels or publish containers. Candidates do not include production updater signing. The normal annotated-tag release remains responsible for signing, full quality checks, platform smokes, draft-asset verification and publication. Published tags and assets must not be overwritten.

Real-client protocol checks and manual desktop use have not been performed for these candidates. Refer to the workflow results for automated validation; do not infer manual validation from them.
