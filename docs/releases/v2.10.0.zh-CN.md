# v2.10.0

[English](v2.10.0.md)

## 升级

无需数据库迁移。数据库结构仍为 v66，可移植导出仍为 payload V12，可直接打开 v2.9.0 的数据目录。备份与回退请参阅[升级与备份指南](../user/upgrade-backup.zh-CN.md)。

本版新增 Dashboard V4 页面与操作接口，按产品版本规则作为次版本发布。既有 V4 路由继续保留。

## 变更

- 账号、供应商和别名改为从本地网关分页读取。搜索和筛选覆盖完整的已保存数据；编辑和批量操作按需加载所需的完整数据。
- 刷新时保留当前页面内容，防止写入、导航、退出登录或网关重启后的迟到响应覆盖新状态。
- 供应商模型保存后，即使页面仍在刷新，也可继续下一次编辑。切换供应商时清理上一家的模型和编辑缓存，避免读取失败后显示并操作另一家的模型。
- 由网关提供账号操作、模型测试选项、用量编辑窗口和刷新资格。平台用量自动读取保留已保存的模型、分组和价格。
- 由网关提供账号提醒和每日 Token 汇总。30 天图表使用 UTC 日期；账号读取失败不会显示为全部正常。
- 后续刷新失败时保留已确认的用量修改。钱包和月用量分别显示各自单位，额度桶区分生效、过期和尚未开始。

## 验证

在 Windows、Node.js 22.23.3 下，Web 生产构建通过，前端测试 1524/1524 通过，工具测试 123/123 通过。两套 Dashboard 契约检查及候选 CLI 构建通过。CI 修正后，仪表盘汇总测试 7/7、供应商契约测试 16/16 通过，Windows 桌面及非桌面工作区所有目标的 Clippy 均在禁止警告的配置下通过。

浏览器连接隔离候选网关，验证了账号筛选与启停、模型路由修改后保存并立即重新编辑、别名展示开关重载后保留，以及返回已选供应商。Key 显示为遮罩，浏览器无控制台错误或警告。截图和日志位于 `.artifacts/acceptance/`。测试网关及回环监听进程已停止，清理检查通过。

隔离 Gateway Lab 的 98 个场景全部通过，FAIL / UNSUPPORTED / NOT_RUN 均为 0，`remoteCalls=0`，进程和端口清理通过。报告位于 `.artifacts/gateway-lab/20261007T130552Z-fb679859/report.json`。供应商切换回归用例在修复前失败；修复后相关 store 与视图测试 32/32 通过。第二次浏览器验收向新选供应商的模型读取注入 503，确认没有保留上一家的模型；移除故障后，重试加载了正确模型。唯一的控制台错误来自注入的 503，清理检查通过。

最终提交须先通过 main 的 Quality 工作流再打标签。发布工作流检查 Windows、macOS、Linux 包和更新签名，独立容器工作流检查两种架构及匿名拉取。

本次准备未进行真实供应商调用或原生桌面交互试用。Windows 安装包没有 Authenticode 签名；macOS 应用使用 ad-hoc 签名，未经公证。
