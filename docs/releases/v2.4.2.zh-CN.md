## 仅针对 main 的质量修复

原始 main 存在两条 Alias 预期、四条 Rust 夹具和两处 lint 失败。本补丁保留 Go 原始模型别名和显式协议安全策略：未知目录 ID 不代表支持 Chat。测试覆盖未知 Zen 模型的启用、关闭与重置，未知 Go 模型的 Auto 与 ForceOn 区别，禁用协议的原始 Alias 行，以及显式启用代理路由后的移除。两处 lint 修复仅删除未使用导入并直接使用切片成员判断。

修复先生成基于 main 的 Git 提交对象，不新建分支。现有完整 Quality 门禁验证这一确切提交后，才允许推进 main 和更新版本；不跳过或删除失败测试。验证状态以实际工作流结果为准，本文不预先宣称通过。
