# v2.4.2

[English](v2.4.2.md)

仅基于 main 的修复候选包，原生构建源码为 `7981406ad532d2f730b062c0d5900242e3d5f658`。包含 v2.4.1 之后已合入 main 的变更，以及下述质量修复，不引入未合并的功能分支。

## 变更

- 修复 Command Code GOAT 临时或未知 429 的处理：没有有效的上游截止时刻时，只为当前请求尝试其它合格账号，不写入账号冷却，也不替换仍然可用的全局粘性目标。有效的 `Retry-After` 或已识别套餐窗口重置时刻仍用于真正的冷却（[#66](https://github.com/klarkxy/open-console-gateway/pull/66)）。
- 识别 GOAT 明确的余额不足 HTTP 400，继续尝试其它合格账号，而不是立即将该账号的拒绝返回客户端。恢复时间未知就保持未知，不虚构冷却或认证失败（[#65](https://github.com/klarkxy/open-console-gateway/pull/65)）。
- 保留 Go 公开目录无凭据获取和动态模型别名。目录回归测试验证只发送一次 GET，且不携带 Authorization、API Key、Cookie 或请求体。
- 保留显式协议启用策略：未知模型 ID 不代表支持 Chat。回归覆盖 Auto、ForceOn、ForceOff 切换，官方文档不可用时重置不改变配置，以及显式启用的代理路由被移除后的行为。
- 修正过期的模型列表与协议测试夹具，按当前运行时目录验证。缺少价格条目不能隐藏已启用的 Go 模型；禁用的协议不能变为可路由状态。
- 修复阻塞发版的未使用导入和切片成员判断 lint 问题。默认测试命令补入现有工具链回归测试。
- package、Rust、Tauri 和 Compose 版本同步至 2.4.2。工作区锁文件由 Cargo 生成，校验确认外部依赖没有变更。

## GOAT 恢复行为的适用范围

截至 2026-09-19 核对，最新公开稳定版仍为 v2.4.1，该二进制不包含 #65 或 #66。两项源码修复均已包含在本次 2.4.2 候选包中，但候选包构建成功不代表稳定版自动升级已经可用。[#62 的 9 月 19 日复现](https://github.com/klarkxy/open-console-gateway/issues/62#issuecomment-5739916214)发生于 v2.4.1，并非修复源码或本候选包。

修复后，正常粘性账号 A 的临时 429，接上账号 H 明确余额不足的 400，可以在同一请求中继续尝试第三个合格账号。没有上游截止时刻时，两种错误都不会使 A 或 H 持久不可用；原本仍可用的 A 保持粘性目标。但如果 H 本来就是粘性目标，新请求仍可能先尝试 H 再回退，因此仅有请求内回退并未解决重复失败尝试的延迟。若没有任何合格账号成功，请求仍会失败。

明确余额不足、但恢复时间未知时的跨请求等待重探，另由 [#71](https://github.com/klarkxy/open-console-gateway/issues/71) 跟踪。#65、#66 和本候选包均未实现该能力。未来的本地探测计划不能伪装成上游额度重置，也不能把无关的临时 429 重新变成账号冷却。
