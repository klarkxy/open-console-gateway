# v2.6.1

[English](https://github.com/klarkxy/open-console-gateway/blob/v2.6.1/docs/releases/v2.6.1.md)

## 升级

升级前停止使用数据目录的进程，并备份整个目录。本版不改变数据库 schema。可配置 HTTP 连接现在可以保存新的 `api_key` 鉴权值；v2.6.0 无法识别该值。如果保存这类连接后需要回退，请恢复升级前的备份。

更新 OCG 不会改写已有连接。若要使用新版预设路由，在连接编辑页选择**采用预设协议**，复核地址和 Key 授权后保存。

## 变化

- 对照运营方文档重新核对全部 55 项供应商预设，补齐已确认的 Chat Completions、Responses 和 Messages 路由。选择器会展示整组路由和鉴权方式；Azure OpenAI 与 Bedrock 在填写匹配的资源或地区地址后补齐其他路由。Azure 静态 API Key 使用 `api-key` 请求头。逐项依据见[预设与来源表](https://github.com/klarkxy/open-console-gateway/blob/v2.6.1/docs/user/provider-presets.zh-CN.md)。
- GOAT 首次模型目录快照按套餐包含的模型设置默认启用状态。以后刷新中新发现的模型采用通常的默认启用规则；已保存的手动开关仍优先。
- Zen Free 通道或 OpenRouter 免费模型路线被拒绝时，短暂冷却该路线并尝试下一条兼容路线。OpenRouter Free 不会把付费目录模型自动启用为免费路线，也不会扣除本地付费 Credit 估算。

## 验证

Windows 本地检查已通过：`pnpm run test`（772 项 Web 测试、工具检查和 Rust 全工作区测试）、设计规范检查、V3/V4 契约检查、Rust 格式检查、Compose 配置检查、`release:check`，以及 Windows 安装包和 CLI 构建。两个发布文件的校验和都与 `SHA256SUMS` 一致；打包后的 CLI 报告版本 `2.6.1`。Gateway Lab 使用该 CLI 运行，98 项 PASS，FAIL/UNSUPPORTED/NOT_RUN 均为 0，`remoteCalls=0`，并确认进程和监听器已清理。正式发布 CI 会在公开前另行构建并验证各平台签名更新包。

本地检查未使用真实供应商凭据，也未运行安装器交互、真实客户端及其他平台的桌面检查。部分 Messages 完整地址按运营方公布的 SDK Base URL 与标准 `/v1/messages` 路径补全；具体模型和套餐是否可用仍取决于上游账号。

更新包使用 Tauri minisign 签名。Windows 安装器无 Authenticode 签名；macOS 应用使用 ad-hoc 签名，未公证。
