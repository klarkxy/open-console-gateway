# v2.6.3

[English](v2.6.3.md)

## 升级

数据库保持 schema v63。升级前退出所有使用数据目录的进程，并备份整个目录。已保存的临时停调规则在重启后保留，活动等待不保留；便携账号导出不包含这些规则。旧版本不会执行新规则，回退时请恢复升级前备份。

## 变更

- 设置页新增全局和按连接配置的临时停调规则：匹配结构化上游错误、查看本地等待、清除等待而不发送探测。内置 GOAT 额度拒绝规则，重试使用正常客户端请求，并继续遵守独立的 Retry-After 限制。
- 通过正在运行的 DSH Web 或官方 Desktop 地址安装、替换和卸载 OCG 插件。检测本地 Profile，使用所选 Home 的会话，区分已应用、需要重启和结果未确认。DSH Editor Profile 保留独立的本地安装路径。
- 保存规则和清除等待使用所显示数据的版本及进程标识，避免覆盖并发修改；重置账号冷却后，较早请求的错误回包不能重新创建等待。
- 账号页可见时刷新过期用量；别名隐藏已禁用映射；模型列表支持选择当前显示行或全部筛选结果。
- 日志将成功但缺少价格的请求展示为成功，并纳入成功筛选。缺少价格仍不等于零费用。
- 更新吉祥物、桌面图标和网站图标，修订中英文用户与维护文档。Codex 集成文档仍是方案，尚未启用该功能。

## 验证

Windows 本地检查使用 Node.js 22.23.3，已通过针对性前端测试、88 项 Gateway Lab 工具测试、Web 构建、V4 契约检查、Rust Clippy、35 项恢复逻辑测试、48 项 DSH Host 测试和 20 项策略/资源 HTTP 测试。临时停调 Lab 的 20 个场景全部通过，远端调用为零，进程和端口清理已验证。DSH CLI 0.1.7-rc.2 通过插件凭据导入、loopback 流式调用、Home 发现和 Editor Profile 安装；隔离的 DSH Web 与本机安装的官方 Desktop Host 均通过经 OCG 发起的安装、替换和卸载，原有插件列表保持完整。此次 Desktop 运行报告未提供版本号。标签对应的精确提交还需通过 main Quality、原生打包和容器发布流程。

本次发布准备没有调用真实供应商、交互测试安装器或运行 macOS/Linux 桌面会话。更新包使用 Tauri minisign 签名；Windows 安装器没有 Authenticode 签名，macOS 应用采用 ad-hoc 签名且未公证。
