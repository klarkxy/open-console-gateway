# v2.10.0

[简体中文](v2.10.0.zh-CN.md)

## Upgrade

No database migration. The schema stays at v66 and portable export stays payload V12. A v2.9.0 data directory opens directly. See the [upgrade and backup guide](../user/upgrade-backup.md) for backup and rollback.

This is a minor release under the product version policy because it adds Dashboard V4 page and operation interfaces. Existing V4 routes remain available.

## Changes

- Load Accounts, Providers and Aliases through paged views from the local gateway. Search and filters cover the complete saved inventory; editors and bulk operations load the complete data they need.
- Keep current page content visible while refreshing. Guard late responses across mutations, navigation, logout and gateway restart.
- Keep consecutive provider model edits usable while the previous save refreshes the page. Clear the previous provider's model and edit cache when switching providers, so a failed read cannot expose another provider's rows.
- Read account actions, model-test choices, quota editing windows and refresh eligibility from the gateway. Automatic platform quota reads preserve saved models, groups and prices.
- Read account attention and daily token summaries from the gateway. Use UTC dates for the 30-day chart and keep a failed account read distinct from an all-clear result.
- Preserve confirmed quota edits when a later refresh fails. Display wallet and monthly usage values with their own units, and expose active, expired and scheduled credit buckets separately.
