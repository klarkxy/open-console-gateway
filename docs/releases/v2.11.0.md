# v2.11.0

[简体中文](v2.11.0.zh-CN.md)

## Upgrade

The database migrates from v66 to v67. Before changing an existing database, OCG creates a verified `data.sqlite.pre-v67.<timestamp>.bak` and SHA-256 sidecar. The migration preserves saved Kimi and GOAT public names and supported GOAT protocol declarations; operator renames and disabled choices stay intact. Portable export remains payload V12. Earlier binaries cannot open schema v67: restore the pre-upgrade database with its matching encryption key, or the complete pre-upgrade data directory, to roll back. See [storage migrations](../maintainer/storage-migration.md) and [upgrade and backup](../user/upgrade-backup.md).

After upgrading, update the DSH plugin through **Applications → DSH** and restart DSH when prompted. VS Code users install the bundled OCG extension through **Applications → VS Code Copilot**, then open or reload the selected Profile. The provider supports Chat and agents; it does not provide inline completions or Next Edit Suggestions.

This is a minor release under the product version policy because it extends Dashboard V4 application interfaces and adds reviewed client-configuration and VS Code extension integration.

## Changes

- Derive built-in aliases from the complete saved model catalog, preserve exact raw model IDs, and handle name collisions across each provider's inventory. Fresh GOAT rows require official protocol evidence for default enablement; saved disabled choices persist.
- Refresh Configurable HTTP catalogs using the saved route and an authorized credential, with revision and identity checks after discovery. Catalog refresh does not grant new access.
- Add read-only previews and reviewed updates for Codex, Kimi Code, MiniMax Code and ZCode configuration. Preserve unrelated settings, detect concurrent edits, and support undoing an adopted OCG block within its ownership limits.
- Keep repeated application configuration responsive with large model catalogs by calculating shared route information once per preview.
- Add a bundled VS Code model provider with Profile-specific installation, encrypted connection storage, dynamic model discovery, public aliases in the picker, declared reasoning choices and Chat/Responses/Messages support. Missing token limits remain visible for correction in OCG.
- Normalize legacy DSH reasoning replay before sending and retain the signed route check before adapter conversion.
- Use eligible saved models for connection verification instead of relying on fixed model lists.
