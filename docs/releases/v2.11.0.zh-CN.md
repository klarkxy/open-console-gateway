# v2.11.0

[English](v2.11.0.md)

## 升级

数据库由 v66 迁移到 v67。修改已有数据库前，OCG 会创建经过校验的 `data.sqlite.pre-v67.<timestamp>.bak` 及 SHA-256 校验文件。迁移保留已保存的 Kimi、GOAT 公共名称及受支持的 GOAT 协议声明，保留用户改名和禁用选择。便携导出仍为 payload V12。旧版程序无法打开 schema v67；回退时需恢复升级前的数据库及匹配的加密密钥，或恢复完整的升级前数据目录。参见[存储迁移](../maintainer/storage-migration.zh-CN.md)与[升级及备份](../user/upgrade-backup.zh-CN.md)。

升级后，通过 **应用 → DSH** 更新插件，并按提示重启 DSH。VS Code 用户通过 **应用 → VS Code Copilot** 安装内置的 OCG 扩展，再打开或重新加载所选 Profile。该提供程序支持 Chat 和智能体，不提供行内补全或 Next Edit Suggestions。

按产品版本规则，本次扩展了 Dashboard V4 应用接口，并新增需审阅确认的客户端配置和 VS Code 扩展集成，因此发布 minor 版本。

## 变更

- 从完整的已保存模型目录生成内置别名，保留精确的原始模型 ID，并按各 Provider 的完整目录处理名称冲突。新发现的 GOAT 行只有获得官方协议证据才默认启用；已保存的禁用选择继续保留。
- 按已保存的路由和已授权凭据刷新 Configurable HTTP 目录，并在发现完成后校验修订号和身份。目录刷新不授予新的访问权限。
- 为 Codex、Kimi Code、MiniMax Code、ZCode 配置新增只读预览和审阅后更新，保留无关设置，检测并发修改，并在字段归属允许的范围内撤销接管的 OCG 配置块。
- 每次预览只计算一次共享路由信息，避免大模型目录反复配置时长时间等待。
- 内置 VS Code 模型提供程序，支持按 Profile 安装、加密连接存储、动态模型发现、选择器公共别名、声明的推理选项及 Chat/Responses/Messages。缺少 token 上限的模型会显示出来，供用户在 OCG 中补全。
- 发送前规范化旧版 DSH 推理回放，并在适配器转换前保留签名路由校验。
- 连接验证使用符合条件的已保存模型，减少对固定模型列表的依赖。

## 验证

Windows、Node.js 22.23.3 环境下，114 项受影响的前端及工具测试、Dashboard V4 契约检查、内置扩展一致性检查、发布预检、Web 生产构建和候选 CLI 构建均通过。

修正大目录更新开销和 Windows 测试夹具路径后，28 项原生配置更新回归测试通过，包括 250 模型的 Codex 不变配置往返，以及五客户端的 Provider 路由变更判断。

隔离的原生 CLI 验收通过 Codex、Kimi、MiniMax、ZCode 和旧版 Copilot 配置适配器的配置、重复更新、接管、撤销与移除流程，每个客户端导出 250 模型，共完成 31 项更新检查。未触碰真实用户目录，临时数据已清理。两项受影响的 GOAT 目录及协议约束回归测试也已通过。

隔离的 Gateway Lab 通过 98/98 个场景，`remoteCalls=0`，进程及端口清理已验证。报告：`.artifacts/gateway-lab/20261009T084423Z-07f7939b/report.json`。隔离的 VS Code Insiders 1.142.0-insider 扩展宿主验证了原生安装与卸载、三个模型注册及协议请求、目录刷新，以及断开连接后删除加密连接信息。该检查使用原生 API，不代表可见模型选择器的交互验收。

发布提交必须通过 main Quality；发布工作流验证 Windows、macOS、Linux 安装包及更新签名，独立的容器工作流验证两种架构及匿名拉取。

本次发布准备不包含真实供应商请求或 macOS/Linux 客户端交互试用。Windows 安装包没有 Authenticode 签名；macOS 应用使用 ad-hoc 签名，未经 notarization。
