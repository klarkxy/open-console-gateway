# v2.6.2

[简体中文](v2.6.2.zh-CN.md)

## Upgrade

This patch keeps database schema v63; no data migration is required. Back up your data directory before upgrading.

**Refresh model catalog** now appends protocol routes missing from an older preset-based connection before refreshing its models. Existing addresses and authentication stay unchanged. New routes receive no Key grants; review grants in the connection editor before using them.

## Changes

- Refresh the dashboard layout, theme controls and keyboard navigation. Page navigation uses hash routes and accepts existing `?view=` links.
- Fold account cards and use compact sort mode to reorder cards and Keys. Folded state survives reloads. Aliases show configured routing ranks and platform origins.
- Reduce repeated page loads, billing reads and large-list rendering. Provider branding uses the saved preset identity, and the model matrix initially limits rendered rows.
- Fix immediate sorting after a Key toggle or platform rename, keep Vue row fragments intact after dragging, and preserve remote-browser pointer coordinates when the picture scales.
- Reuse successful Quality checks for the exact release commit and automatically start container publication after desktop assets are published.

## Verification

Local Windows checks passed: 820 frontend tests under Node.js 22, 96 tooling tests, web build and release preflight. Browser checks with isolated dummy data passed for Key masking/copying, immediate sorting after a toggle, pointer dragging followed by deletion, Aliases, history navigation and a 390 px layout. Gateway Lab passed all 98 scenarios with zero remote calls and verified process/port cleanup. Native noVNC scaling passed coordinate probes; a live remote desktop session was not exercised.

Final main Quality, native packaging and container publication are separate release gates. No real supplier calls, interactive installer checks or macOS/Linux desktop sessions were run locally.

Updater payloads carry Tauri minisign signatures. Windows installers have no Authenticode signature; macOS apps use ad-hoc signing and are not notarized.
