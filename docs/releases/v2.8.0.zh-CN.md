# v2.8.0

[English](v2.8.0.md)

## 升级

升级前停止使用数据目录的进程，并备份整个目录。v2.7.0 数据库由 schema v64 迁移到 v66：v65 增加操作回执与逻辑请求分组索引，v66 按 Key 保存 GOAT 套餐重置窗口。v65 迁移会先为已有数据库创建经过校验的 SQLite 备份。旧版本拒绝打开 v66；回退必须恢复完整的升级前数据目录。详见[迁移指南](../maintainer/storage-migration.zh-CN.md)。

便携导出改为 payload V12，继续支持导入 V4–V11；旧版本无法导入 V12。需要旧版本读取时，请保留旧格式导出。

停用实时参考价格、价格倍率和基于价格的估算扣费。历史费用与 credit 回执保留，打开数据库不会结算或重新定价。供应商余额与配额观测仍然可用。已退役的 dashboard 定价路由已移除。

本次除修复外，还扩展日志查询接口和持久化操作记录，按产品版本规则发布为次版本。

## 变更

- 分开记录逻辑请求、操作回执和程序诊断。日志页按请求聚合尝试，操作单独展示。原生程序日志在数据目录内轮转，保留凭据脱敏与私有权限；Docker 继续使用 stderr。
- 发布原子的请求准备快照，减少每次请求重复读取控制面造成的等待，发送上游前仍检查凭据有效性。
- 按 GOAT Key 分别处理五小时、周和月重置窗口，支持重启与便携迁移。手动恢复和实际换 Key 只清除所选 Key 的本地窗口。
- 在 Rust 中缓存账单快照，配额刷新不再等待较慢的余额读取。防止退出登录、账号替换和视图销毁后的迟到响应覆盖状态。
- 修复账号、供应商、Key、别名、设置和 CPA 页面中的保存、删除、重新验证与 KeepAlive 生命周期。后续读取失败时保留已确认的写入结果。
- 展示别名映射能力并链接到能力声明。按字段从 models.dev 补齐缺失元数据，保留已配置的推理偏好。
- 限制请求调试捕获与程序日志文件，拒绝链接路径并保留凭据脱敏。缩小开发模式的监听目录，正确处理 Windows 可执行文件路径。

## 验证

Windows 上使用 Node.js 22.23.3 的本地发布预检、Web 生产构建、两套 dashboard 契约检查和 CLI 构建已通过。隔离的本地 Gateway Lab 是运行验收门槛：打标签前要求所有场景通过、远程调用为零，并确认自有进程和端口已关闭。

打标签前，最终提交必须通过 main Quality。发布工作流在正式发布前验证 Windows、macOS、Linux 安装包及更新签名；独立容器工作流验证两种架构和匿名拉取。

本次准备不包含真实供应商调用，也不包含 macOS/Linux 桌面交互。Windows 安装包没有 Authenticode 签名；macOS 应用使用 ad-hoc 签名，未公证。
